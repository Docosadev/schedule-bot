# プライバシーポリシー

最終更新: 2026-07-26

このBotは日程調整を提供するため、DiscordのサーバーID、チャンネルID、ユーザーID、ロールID、投票内容、日程調整のタイトル・候補日時・締切、Botのサーバー別設定を保存します。メッセージ本文やDiscordアカウントの認証情報を網羅的に収集することはありません。

保存した情報は、投票の表示・集計・リマインド・開催案内、障害調査、不正利用防止のためだけに使用し、法令上必要な場合を除いて第三者へ販売・提供しません。通信先と保存先にはDiscord、Render、Neonなど運用に必要なサービスが含まれます。

終了済みの日程調整データは標準で90日後に削除します。サーバー管理者は `/schedule-delete-data confirm:DELETE` で、そのサーバーの保存データを削除できます。問い合わせ窓口からサーバーIDと削除対象を伝えて削除を依頼することもできます。
